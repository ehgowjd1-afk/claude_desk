# 설치 없이 크롬 콘솔에서 쓰는 방법

Node.js 설치가 필요 없습니다. 이미 로그인해서 보고 계신 크롬 창에서 그대로 돕니다.
로그인 쿠키가 자동으로 붙기 때문에 소장 중인 작품의 댓글도 그대로 읽힙니다.

## 1단계 — 구조 파악 (`1-probe.js`)

1. 크롬에서 리디에 로그인한 상태로, 수집할 작품의 **회차 하나**를 엽니다.
2. `F12` → **Console** 탭.
3. 붙여넣기가 막히면 콘솔에 `allow pasting` 을 입력하고 Enter (크롬 보안 기능, 한 번만).
4. [1-probe.js](1-probe.js) 내용을 통째로 복사해 붙여넣고 Enter.
5. 30초 동안 페이지를 아래로 쭉 스크롤해 **댓글이 화면에 보이게** 합니다.
   (기다리기 싫으면 `리디탐색끝내기()` 입력)
6. `ridi-probe.json` 이 자동 다운로드됩니다. 이 파일을 주시면 2단계 스크립트를 만들어 드립니다.

수집되는 것: 회차 링크 목록, 화면에 보이는 댓글 수 텍스트, 댓글 관련 네트워크 요청과 응답.
계정 정보나 쿠키는 담기지 않습니다.

## 2단계 — 전 회차 수집

1단계 결과를 보고 `2-collect.js` 를 만들어 드립니다. 같은 방식으로 콘솔에 붙여넣으면
회차를 순회하며 댓글 수를 모아 CSV 파일로 다운로드합니다. 이 단계도 설치는 필요 없습니다.
